# ORACUL — Telegram Mini App

Бело-оранжевый мини-апп с загрузочным экраном в стиле стекла (glassmorphism)
и ИИ-чатом «Оракул» на базе Groq API.

## Что внутри

```
oracul/
├── public/
│   ├── index.html   — разметка (экран загрузки + чат)
│   ├── style.css     — вся стилистика: стекло, блюр, орб-анимация
│   └── app.js         — Telegram WebApp SDK, переход загрузка→чат, логика чата
├── server.js          — прокси-сервер: держит ключ Groq в секрете
├── package.json
└── .env.example
```

Ключ Groq **никогда** не должен попадать в браузер — поэтому все запросы
идут через `server.js`, а фронтенд стучится только в `/api/chat`.

## 1. Запуск локально

```bash
npm install
cp .env.example .env
# вписать свой ключ в .env: GROQ_API_KEY=...
npm start
```

Сервер поднимется на `http://localhost:3000`.

## 2. Получить ключ Groq

1. Зайти на https://console.groq.com/keys
2. Создать API-ключ, вставить в `.env` как `GROQ_API_KEY`
3. При желании поменять модель через `GROQ_MODEL` (по умолчанию `llama-3.3-70b-versatile`)

## 3. Зарегистрировать мини-апп в Telegram

1. Открыть **@BotFather** → создать бота (`/newbot`), если его ещё нет
2. `/newapp` → выбрать своего бота → указать название **ORACUL**, картинку, описание
3. В качестве **Web App URL** указать публичный HTTPS-адрес, где задеплоен сервер
   (Telegram не пускает мини-аппы по http:// и localhost)

## 4. Задеплоить на публичный HTTPS

Для теста быстрее всего:

```bash
npm install -g ngrok
ngrok http 3000
```

и указать выданный `https://xxxx.ngrok-free.app` как Web App URL в BotFather.

Для продакшена — любой Node-хостинг: Render, Railway, Fly.io, VPS + nginx.
Главное — задать `GROQ_API_KEY` как переменную окружения на хостинге (не коммитить `.env`).

## Дизайн

- Палитра: тёплый белый фон + оранжевый акцент (`#FF6B1A` / `#FF8A3D`), тёплый
  тёмно-коричневый текст вместо чистого чёрного
- Заголовки — Cormorant Garamond (мистика/оракул), интерфейс и текст — Inter,
  технические метки — JetBrains Mono
- Загрузочный экран: стеклянный «орб» с дыханием (пульс), двумя вращающимися
  орбитами-кольцами и свечением — при готовности плавно размывается и исчезает,
  открывая чат
- В чате орб уменьшается до аватарки в шапке — визуальная связка с загрузкой
- Сообщения — стеклянные полупрозрачные пузыри с блюром у Оракула,
  сплошной оранжевый градиент у пользователя

## Настройка личности Оракула

Системный промпт задаётся в `server.js` (константа `SYSTEM_PROMPT`) — там же
удобно скорректировать тон ответов, длину, стиль.
